# Les repas de Noah 🦁🍼🤱

Petite appli web pour suivre les repas de Noah (biberons et allaitements), voir en direct depuis combien de temps il a mangé, et les totaux d'aujourd'hui et des dernières 24 heures. Décor savane animé (girafe qui boit, éléphant, oiseaux, suricate), avec un mode nuit automatique.

- Site statique (HTML / CSS / JS), hébergé sur GitHub Pages
- Données dans Supabase (table `biberons`, colonne `type` : biberon ou allaitement)
