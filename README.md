# Les biberons de Noah 🦁🍼

Petite appli web pour compter les biberons de Noah, voir en direct depuis combien de temps il a bu le dernier, et le total sur aujourd'hui et sur 24 heures. Décor savane, avec un mode nuit automatique.

- Site statique (HTML / CSS / JS), hébergé sur GitHub Pages
- Données dans Supabase (table `biberons`)
